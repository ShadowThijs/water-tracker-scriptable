# water-tracker-scriptable

Simple widget to track amount of water drank and remind to drink more through notifications
No external API is needed

## To install

Copy the contents from `water-tracker.js` or download the javascript file and import it into scriptable

## To use

Add the widget to your screen, select the 4x2 option and to add watee click the widget and click the button to enter the amount you drank at that time
